## Controls

| Button | Action |
|--|--| 
|A|mouse_left|
|B|mouse_right|
|Y|select paperdoll [I]|
|X|undo [Backspace]|
|A[SHIFT]|attention [S-MLB]|
|B[SHIFT]|add/remove target [S-MRB]|
|Y[SHIFT]|target paperdoll [S-I/O]|
|X[SHIFT]|eject/cancel drop [S-Backspace]|
|A[HOTKEY]|scroll map [S]|
|B[HOTKEY]|scroll map [D]|
|Y[HOTKEY]|scroll map [W]|
|X[HOTKEY]|scroll map [A]|
|L1|SHIFT|
|L1[HOTKEY]|talk [T]|
|L2|reset view [Q]|
|L2[HOTKEY]|zoom out [F]|
|L3|main menu [F10]|
|R1|mouse_slow|
|R1[HOTKEY]|console [`]|
|R2|zoom to active area [E]|
|R2[HOTKEY]|zoom in [R]|
|SELECT|ESC|
|START|confirm action [ENTER]|
|UP|forward [UP]|
|DOWN|backward [DOWN]|
|LEFT|rotate left [LEFT]|
|RIGHT|rotate right [RIGHT]|
|LEFT_ANALOG|mouse|
|RIGHT_ANALOG|WASD|

### Interactive Input Mode Controls
START+D-PAD DOWN to activate
once activated
D-PAD UP = previous letter
D-PAD DOWN = next letter
D-PAD RIGHT = next character
D-PAD LEFT = delete and move back one character
L1 = jump back 13 letters for current character
R1 = jump forward 13 letters for current character
A = send ENTER key and exit mode
SELECT/HOTKEY = cancel and exit mode (deletes all characters)
START = confirm and exit mode (also sends ENTER key)
